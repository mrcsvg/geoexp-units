# geoexp-units

Ready-made unit hierarchies for [geoexp](https://github.com/mrcsvg/geoexp):
which coarser units each fine unit belongs to, so a panel collected at one
level can be designed at another.

```python
import geoexp_units
from geoexp import aggregate_panel

ibge = geoexp_units.br.ibge()  # or geoexp_units.load("br.ibge")
by_state = aggregate_panel(
    panel,  # long panel keyed by IBGE municipality code
    unit="municipio",
    time="date",
    outcome="sales",
    hierarchy=ibge,
    to="uf",
    use_labels=True,  # "SP", "RJ", ...
)
```

`geoexp_units.available()` lists what ships:

| Name | Levels | Source |
|---|---|---|
| `br.ibge` | `municipio -> regiao_imediata -> regiao_intermediaria -> uf -> regiao` | IBGE, API de Localidades |
| `br.ibge`, `legacy=True` | `municipio -> microrregiao -> mesorregiao -> uf -> regiao` | same |

Units are keyed by the 7-digit IBGE municipality code (`Int64`). Every level
carries a label: names, and the two-letter abbreviation for `uf`. The legacy
division was frozen by IBGE in 2017, so municipalities created since have no
micro- or mesorregião; `legacy=True` leaves them out and warns with their
names instead of inventing one.

Labels are refused where they do not identify a unit: there are two
regiões imediatas called "Itabaiana" (PB and SE), so
`use_labels=True` at that level raises instead of adding them together. Codes
always work; UF abbreviations and region names are unique.

Matching by municipality *name* is not supported yet: names repeat across
states and vary in spelling. Join on the code.

## How it fits with geoexp

geoexp owns the contract (`geoexp.Hierarchy`, `geoexp.aggregate_panel`); this
package only ships data built on it. You can build your own hierarchy — stores
to sales districts, zip codes to media markets — with
`geoexp.Hierarchy.from_frame` and never touch this package. To contribute one
here: a module that returns a `Hierarchy`, its data under
`src/geoexp_units/data/`, a script that regenerates the data, and one entry in
`_registry.py`.

## Data and licence
